## Brand & Style

This design system establishes a high-focus, meditative digital environment inspired by modern minimal operating environments and Japanese lacquered koi ponds at night. It merges the austere discipline of Unix-style desktop workspaces with liquid organic accents—balancing dark ink obsidian voids with the fluid grace of vibrant bioluminescent aquatic life.

### Target Audience & Emotional Intent
- **Audience:** Developers, interface enthusiasts, systems architects, and power users seeking an uncluttered, high-craft desktop launcher and browser chrome workspace.
- **Atmosphere:** Deeply calm, contemplative, ultra-precise, and frictionless. Surfaces recede into total darkness while vital interactions glide smoothly across the screen like koi under dark pond water.
- **Design Movement:** Dark minimalism married to optical Glassmorphism and refined micro-borders. Visual density is strictly calibrated; heavy UI ornamentation is removed in favor of structural clarity, ultra-thin borders, and selective photonic glows.

## Colors

The palette is engineered around an ink-black void punctured by the luminous colors of Japanese Nishikigoi (ornamental carp).

- **Primary (`#38BDF8` - Glacial Cyan):** Cold, clear water refraction. Applied to active tabs, terminal focus indicators, cursor elements, and telemetry data.
- **Secondary (`#F59E0B` - Kohaku Amber Gold):** Warm, metallic, reflective scales. Used for system alerts, bookmarks, pinned favorites, and critical metric badges.
- **Tertiary (`#FF5722` - Sanke Glowing Orange):** Bioluminescent organic presence. Reserved for lively kinetic accents, notifications, recording/live pulses, and dynamic execution triggers.
- **Neutral (`#030712` - Deep Obsidian Ink):** Total light absorption. Foundations cascade from true ink (`#030712`) up through obsidian layers (`#0B0F19`, `#111827`) to preserve high optical contrast without ocular fatigue.

### Semantic Tones & Translucency
- **Micro-borders:** Crisp, semi-transparent white overlays (`rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.14)`).
- **Water Glows:** Accent hues are paired with soft ambient diffusion halos at 12–18% opacity to simulate light emitting through still water.

## Typography

The typographic hierarchy harmonizes technical clarity with architectural precision:

- **Space Grotesk (Headlines & System Clocks):** Provides geometric discipline, expressive junctions, and low stroke modulation suited for high-impact time displays, widget headers, and dashboard summaries.
- **Geist (Body & Omnibar Content):** Neutral, hyper-legible neo-grotesque designed specifically for modern UI viewports. It handles URLs, system metadata, search results, and configuration panels cleanly.
- **JetBrains Mono (System Labels, Telemetry, Navigation Shortcuts):** Delivers strict technical alignment for CPU/memory readouts, keyboard hotkeys (`⌘K`, `⌥T`), protocol indicators (`https://`), and console outputs. All numbers and tabular figures must use tabular sizing (`tnum`) for flawless vertical scanning.

## Layout & Spacing

The layout operates on a fluid, modular grid anchored by an ultra-thin desktop taskbar/status bar and a suspended browser chrome dock.

### Grid & Layout Rules
- **Desktop (1024px+):** Pinned 40px taskbar at either the screen top or bottom. The primary viewport uses a central 12-column layout (max-width 1280px) flanked by fluid gutters. Canvas components snap to 4-column widgets or full-span command centers.
- **Tablet (768px - 1023px):** Fluid 8-column layout. Spacing scales to `space-md` gaps. Floating omnibars collapse into a centralized header.
- **Mobile (< 768px):** Single-column stacked stream with fixed edge margins (`margin-mobile`). The taskbar switches to a unified bottom navigation sheet with minimal 36px touch surfaces.

### Rhythmic Density
- Density is deliberately compact to reflect terminal utilities and modern operating system shells.
- Vertical stack separation relies on empty breathing room (`space-md` through `space-xl`), avoiding excessive horizontal divider rules.

## Elevation & Depth

This system avoids muddy dropshadows, relying instead on frosted glass depth, photonic backlights, and crisp micro-borders.

### Surface Elevation Layers
1. **Base Layer (L0 - Obsidian Void):** `#030712` raw backdrop. Can host a faint, slow-moving SVG particle/noise gradient reminiscent of deep water currents.
2. **Structural Panels (L1 - Subsurface Glass):** `rgba(11, 15, 25, 0.65)` with `backdrop-filter: blur(16px)` and a uniform border of `1px solid rgba(255, 255, 255, 0.08)`.
3. **Floating Windows & Omnibar (L2 - Surface Glass):** `rgba(17, 24, 39, 0.75)` with `backdrop-filter: blur(24px)` and a border of `1px solid rgba(255, 255, 255, 0.12)`.
4. **Modals & Overlays (L3 - Active Lens):** `rgba(24, 32, 50, 0.85)` with `backdrop-filter: blur(32px)` and targeted edge highlight `1px solid rgba(56, 189, 248, 0.3)`.

### Lighting & Photonic Shadows
- Panels feature an inner highlight: `inset 0 1px 0 0 rgba(255, 255, 255, 0.1)`.
- Hover and focus states cast faint, luminous koi glows:
  - Cyan Focus: `box-shadow: 0 0 20px -5px rgba(56, 189, 248, 0.35)`
  - Amber Pulse: `box-shadow: 0 0 20px -5px rgba(245, 158, 11, 0.35)`
  - Orange Glow: `box-shadow: 0 0 24px -6px rgba(255, 87, 34, 0.4)`

## Shapes

The interface adopts a disciplined, sharp-edged architectural foundation slightly softened by micro-radii to maintain high density:

- **Tokens:** Level 1 (`roundedness: 1`) designates a foundational radius of `0.25rem` (4px). Standard buttons, input boxes, taskbar icons, and telemetry chips adopt 4px corners.
- **Card Containers & Windows:** Use `rounded-lg` (`0.5rem` / 8px) to frame content gently without appearing bubbly or casual.
- **Omnibar & Command Palettes:** Scale up to `rounded-xl` (`0.75rem` / 12px) to denote detached floating status above the workspace.
- **Micro-borders:** All containers maintain strict 1px boundary lines. Radii must never clip focus rings or glow halos.

## Components

### 1. Ultra-Sleek Taskbar & Browser Chrome
- **Height & Layout:** Fixed 38px height, suspended 12px from edge or flush pinned. Divided into three segments: Left (system identity, virtual workspaces), Center (Omnibar/URL bar), Right (system monitors, network, clock).
- **Chrome Tabs:** Slanted or pill-tab design with zero background in idle state; active tab receives `rgba(255, 255, 255, 0.05)`, top-edge 1px Glacial Cyan line, and active close glyph.
- **Omnibar (Command Palette):** Center-aligned, 34px height. Features `JetBrains Mono` text, subtle magnifying glyph, and trailing `⌘K` badge. On focus, expands gracefully into an elevated frosted modal.

### 2. Buttons
- **Primary:** Background `rgba(56, 189, 248, 0.15)`, text `#38BDF8`, border `1px solid rgba(56, 189, 248, 0.4)`. On hover: background `#38BDF8`, text `#030712`, with cyan photonic glow.
- **Secondary (Obsidian Ghost):** Background `rgba(255, 255, 255, 0.03)`, text `#E5E7EB`, border `1px solid rgba(255, 255, 255, 0.1)`. On hover: `rgba(255, 255, 255, 0.08)`.
- **Accent (Koi Pulse):** Background `rgba(255, 87, 34, 0.12)`, text `#FF5722`, border `1px solid rgba(255, 87, 34, 0.3)`.

### 3. Chips & Status Badges
- Built with `label-tag` typography.
- Compact padding (`0.125rem 0.375rem`), height 18px.
- Micro dot indicator (4px) with continuous breathing animation (amber for warning, glowing orange for live stream/recording, cyan for active link).

### 4. Input Fields & Search Bars
- Background: `rgba(3, 7, 18, 0.6)`.
- Border: `1px solid rgba(255, 255, 255, 0.1)`.
- Font: `Geist` 14px with `JetBrains Mono` placeholder text (`rgba(156, 163, 175, 0.5)`).
- Focus: Border shifts to `#38BDF8` with a 3px diffused outer halo. No standard browser outline.

### 5. Checkboxes, Toggles & Radios
- **Checkbox:** 14px square, 3px border-radius. Inactive: border `1px solid rgba(255, 255, 255, 0.2)`. Checked: filled `#38BDF8` with dark ink checkmark.
- **Switch/Toggle:** 28px width, 16px height track. Obsidian trough with cyan or glowing orange thumb (`12px` circle). Smooth 150ms cubic-bezier transition.

### 6. Cards & App Tiles (Start Page Grid)
- Glassmorphic panels with `backdrop-filter: blur(16px)` and 1px micro-borders.
- Hover Interaction: Card elevates slightly via an inner illumination shift (`rgba(255, 255, 255, 0.04)` overlay) and a bottom-corner glowing koi gradient accent (subtle orange-amber aura).

### 7. Telemetry & Metric Gauges
- Integrated mini-graphs (CPU, RAM, Ping) rendered in 1px monoline strokes using `#38BDF8` or `#F59E0B`.
- Grid reference marks rendered in low-opacity dotted lines (`rgba(255, 255, 255, 0.06)`).
